# ゲームクラスの生成と登録
- ToyLibのゲームクラスはtoy::Applicationクラスを継承して生成します。
- Applicationクラスを継承したゲームクラスを、TOYLIB_REGISTER_APPマクロに渡すことで、インスタンス化しmain()から呼ばれるゲームクラスとして登録されます。
``` C++
    TOYLIB_REGISTER_APP(GameApp)
```

- TOYLIB_REGISTER_APPの中身
``` C++
#define TOYLIB_REGISTER_APP(AppType, ...)                          \

    std::unique_ptr<toy::Application> CreateUserApplication() {    \

        return std::make_unique<AppType>(__VA_ARGS__);             \

    }
```

# Applicationクラスの要素
``` C++

class GameApp : public toy::Application
{
public:
    GameApp();
    void InitGame() override;
    void ProcessInput(const toy::InputState& input) override;
    void UpdateGame(float deltaTime) override;
private:
    std::unique_ptr<toy::kit::GameFlow> mGameFlow;
};

```
## コンストラクタ
- コンストラクタは、Application::Apllication()を継承します。
- AssetManagerが参照するファイルパスなどを登録します。
``` C++
GameApp::GameApp()
    : toy::Application()
{
    GetAssetManager()->SetAssetsPath("ToyGame/Assets/KitGame/");
}
```


## InitGame()
- ゲームに関する初期化処理を行います。
- Application::InitGame()をoverrideすることで、起動シーケンス上の適切なタイミングで呼び出されます。
- toy::kit::GameFlowを使う場合はこのタイミングで生成、初期シーンの登録を行います。
- 
``` C++
void GameApp::InitGame()
{
    mGameFlow = std::make_unique<toy::kit::GameFlow>(this);
    mGameFlow->Init();
    mGameFlow->SetInitialScene(std::make_unique<TitleScene>());
}
```

## ProcessInput() 
- Application::ProcessInput()をoverrideすることでユーザの入力状況を取得できます。
- toy::InputState& inputを引数に取り、InputSystemからの入力状態を受け取ります。
- toy::kit::GameFlowを使う場合は、toy::kit::GameFlow::ProsessInput()に状態を渡します。

``` C++
void GameApp::ProcessInput(const toy::InputState& input)
{
    if (mGameFlow)
    {
        mGameFlow->ProcessInput(input);
    }
}
```

## UpdateGame()
- Application::UpdateGame()をoverrideすることで、ゲームクラスのマイフレーム呼ばれる更新処理を記述することが可能です。
- toy::kit::GameFlowを使う場合は、ここでtoy::kit::GameFlow::Update()を呼び出します。
``` C++
void GameApp::UpdateGame(float deltaTime)
{
    if (mGameFlow)
    {
        mGameFlow->Update(deltaTime);
    }
}
```
